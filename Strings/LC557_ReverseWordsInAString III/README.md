# 557. Reverse Words in a String III

## Problem Statement

Given a string `s`, reverse the characters of every word while preserving:

- The original order of words.
- The whitespace between words.

### Example 1

**Input**

```
Let's take LeetCode contest
```

**Output**

```
s'teL ekat edoCteeL tsetnoc
```

---

### Example 2

**Input**

```
Mr Ding
```

**Output**

```
rM gniD
```

---

# Approach 1: Using `split()` and `StringBuilder`

## Intuition

The easiest way to solve this problem is to separate the sentence into individual words. Once each word is isolated, reverse its characters and append the reversed word to the final result.

Since strings in Java are immutable, `StringBuilder` is used to efficiently build the output string.

---

## Algorithm

1. Split the input string into an array of words using the space delimiter.
2. Create a `StringBuilder` to store the final answer.
3. Traverse every word in the array.
4. Reverse the current word by traversing its characters from the last index to the first.
5. Append the reversed word to the `StringBuilder`.
6. Append a space after every reversed word.
7. Remove the trailing space before returning the result.

---

## Dry Run

Input

```
Let's take LeetCode contest
```

After splitting

```
["Let's", "take", "LeetCode", "contest"]
```

Reverse each word

```
Let's      → s'teL
take       → ekat
LeetCode   → edoCteeL
contest    → tsetnoc
```

Final Output

```
s'teL ekat edoCteeL tsetnoc
```

---

## Time Complexity

```
O(n)
```

where **n** is the length of the input string.

---

## Space Complexity

```
O(n)
```

Extra space is required for:

- The array generated by `split()`
- The output `StringBuilder`

---

## Advantages

- Very easy to understand.
- Beginner-friendly.
- Clean and readable implementation.
- Suitable for interviews when optimization is not the primary concern.

---

## Disadvantages

- Creates an additional array of words.
- Uses more memory because of `split()`.
- Not the most space-efficient solution.

---

# Approach 2: Using Character Array (Two-Pointer Technique)

## Intuition

Instead of splitting the string into multiple words, convert the entire string into a character array.

Each word can then be reversed directly inside the character array using two pointers.

This avoids creating an extra array of words and performs the reversal in-place within the character array.

---

## Algorithm

1. Convert the input string into a character array.
2. Maintain a pointer `start` representing the beginning of the current word.
3. Traverse the character array using another pointer `end`.
4. Whenever a space or the end of the array is encountered:
   - Reverse the characters between `start` and `end - 1`.
5. Move `start` to the first character of the next word.
6. Repeat until the entire array has been processed.
7. Convert the modified character array back into a string.

---

## Dry Run

Input

```
Let's take
```

Character Array

```
L e t ' s _ t a k e
```

### Step 1

Current word

```
Let's
```

Reverse

```
s ' t e L
```

Array becomes

```
s ' t e L _ t a k e
```

---

### Step 2

Current word

```
take
```

Reverse

```
e k a t
```

Final Array

```
s ' t e L _ e k a t
```

Final Output

```
s'teL ekat
```

---

## Time Complexity

```
O(n)
```

Each character is visited a constant number of times.

---

## Space Complexity

```
O(n)
```

A character array is created from the input string. No additional array of words is required.

---

## Advantages

- More optimized than the `split()` approach.
- Does not create an array of words.
- Uses the efficient Two-Pointer Technique.
- Preferred in coding interviews when asked to optimize.

---

## Disadvantages

- Slightly more difficult to understand.
- Requires careful pointer management.

---

# Comparison

# Key Learning

This problem teaches multiple important concepts frequently asked in coding interviews:

- String manipulation
- Character array operations
- Two-pointer technique
- Efficient use of `StringBuilder`
- In-place reversal of characters
- Time and space complexity analysis

Both approaches achieve **O(n)** time complexity.

- If readability and simplicity are the priority, the **split() + StringBuilder** approach is an excellent choice.
- If optimization and interview performance are important, the **Character Array (Two-Pointer)** approach is generally preferred.
