# 53. Maximum Subarray

## Problem Statement

Given an integer array `nums`, find the **contiguous subarray** that has the largest sum and return its sum.

---

## Examples

### Example 1

**Input**
```text
nums = [-2,1,-3,4,-1,2,1,-5,4]
```

**Output**
```text
6
```

**Explanation**

```text
The subarray [4,-1,2,1] has the largest sum = 6.
```

---

### Example 2

**Input**

```text
nums = [1]
```

**Output**

```text
1
```

---

### Example 3

**Input**

```text
nums = [5,4,-1,7,8]
```

**Output**

```text
23
```

---

## Constraints

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

---

## Objective

Return the **maximum possible sum** of any **contiguous subarray**.

---

## Notes

- A subarray must contain **continuous elements**.
- The subarray can consist of a single element.
- The array may contain positive numbers, negative numbers, or both.
